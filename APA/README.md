## APA — Probabilistic Machine Learning

This course introduces the **probabilistic approach to machine learning**, covering:

- Fundamentals of probabilistic machine learning and **information theory**.
- **Dimensionality reduction** with PCA.
- **Gradient descent** and empirical risk minimization.
- **Supervised learning**, focusing on logistic regression and computational methods.
- **Non-parametric models**, especially boosting.
- **Unsupervised learning**, including clustering with k-means.

The course provides practical foundations for developing machine learning systems and prepares students for **deep learning**.
